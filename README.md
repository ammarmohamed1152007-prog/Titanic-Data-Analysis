# Titanic Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python.

The goal of this project is to clean the data, explore passenger characteristics, analyze survival patterns, and extract meaningful insights.

## Objectives

- Understand the dataset structure
- Handle missing values
- Check for duplicate records
- Perform statistical analysis
- Explore relationships between variables
- Create data visualizations
- Extract key insights from the data

## Data Cleaning

The project includes:

- Handling missing values in Age
- Handling missing values in Cabin
- Checking for duplicate records
- Checking data types and dataset structure

## Exploratory Data Analysis

The analysis explores:

- Passenger survival
- Gender distribution
- Passenger class
- Age distribution
- Fare
- Relationships between numerical variables

## Visualizations

The project uses different visualization techniques including:

- Bar charts
- Histograms
- Scatter plots
- Correlation heatmap
- Interactive Plotly visualizations

## Key Insights

- Female passengers had a higher survival rate than male passengers.
- Passenger class was associated with survival.
- Passengers belonged to different age groups.
- Fare and passenger class showed a relationship.
